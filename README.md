# PayReminder

A lightweight SaaS tool that automatically chases overdue invoice 
payments for freelancers and small agencies — so you don't have to.

## What it does

- Add clients and invoices
- Automated, escalating email reminders (friendly → firm) as invoices 
  approach and pass their due date
- One-click Stripe payment link in every reminder
- Reminders stop automatically the moment payment is received
- Simple dashboard showing outstanding, overdue, and paid invoices

## Tech Stack

- **Backend:** Go (Gin)
- **Database:** PostgreSQL
- **Auth:** JWT
- **Email:** Resend
- **Payment:** Stripe
- **Frontend:** React + TypeScript
